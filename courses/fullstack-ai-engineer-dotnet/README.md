# Full-Stack AI Engineer (.NET) Program <!-- omit in toc -->

This course takes interns from their first C# program to full-stack AI applications in .NET. Interns learn the C# language, ASP.NET Core for the backend, Blazor for the frontend, and AI features built with Microsoft Extensions AI and the Microsoft Agent Framework. They also learn to use AI itself for research, learning, content, and development, to verify what models produce, and to keep decisions in human hands. Throughout the course, each intern builds one portfolio application, step by step.

## How the Course Works

Each step has **Study Items** to learn from and **Tasks** to complete. Items marked *(Optional)* deepen a topic but are not required.

Steps 1–3 focus on C# while you start your product with AI research, content, HTML, and CSS. ASP.NET Core starts in Step 4, Blazor in Step 5, and AI features in .NET in Step 9. Steps 10–14 add agents, automated workflows, production readiness, and the capstone.

**The portfolio application.** From Step 1 to the capstone in Step 14, you build and improve one application. Stick with a single product domain for the whole course: a learning tool, research assistant, content workspace, or project assistant all work well. If you'd prefer something else, get your technical mentor's approval first. Keep the application in one GitHub repository, and in every step share a link to the commit that contains the step's work.

**Tasks with acceptance criteria.** Tasks adapted from the CrystaCode bootcamp list a **Goal**, a **Deliverable**, **Requirements**, objective **Acceptance criteria**, and the **Submission** evidence to share. Such a task is complete when every acceptance criterion is met.

## Using AI in This Course

You use AI throughout the course for research, learning, content, and development. Verify important model outputs against reliable sources, record your checks and corrections, and remember that you remain responsible for every decision and every change you accept. Do not share secrets, credentials, or private data with AI tools.

Product interfaces, plans, regional availability, and fast-moving AI libraries can change. When a named product is unavailable, use an equivalent approved by your technical mentor and document the substitution. For version-sensitive .NET AI work, treat the linked videos as conceptual demonstrations and verify APIs, package status, and examples against the linked current official documentation before implementation.

The hashtags of this course are `#fullstack_ai #dotnet`. Use them together wherever the process documents ask for the course name: `#cs_internship #fullstack_ai #dotnet #step1` in posts, commitment messages, and [Step 0](../Step%200.md) introductions, and `#cs_internship #fullstack_ai #dotnet #step_1` in presentation captions.
